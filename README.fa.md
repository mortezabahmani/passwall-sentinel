## 🌟 ویژگی‌های کلیدی

- 🖥️ **رابط کاربری مدرن LuCI Web:** داشبورد تعاملی در محیط وب اوپن‌دبلیو‌آرتی (`Services -> PassWall Sentinel`) با نمایش کارت‌های وضعیت زنده، جدول مقایسه کامل نودها و جدول وضعیت ۵۰ پروایدر دی‌ان‌اس.
- 🔒 **ترافیک ۱۰۰٪ دایرکت و ایزوله:** ارزیابی نودها و ۵۰ پروایدر دی‌ان‌اس مستقیماً از بستر شبکه فیزیکی WAN (با استفاده از سوکت مارک ۲۵۵) بدون گذشتن از هسته یا فیلترشکن فعال.
- 🛡️ **مکانیزم رول‌بک مسلح و ضد بریک (Armed Rollback):** هر تغییر با یک تایمر سلامت ۶۰ ثانیه‌ای محافظت می‌شود؛ در صورت اختلال در دسترسی اینترنت، سیستم فوراً به اسنپ‌شات قبلی بازمی‌گردد.
- 🚨 **نگهبان نجات اضطراری (Failsafe Watchdog):** در صورت فریز شدن، قطع سراسری یا کرش پسوال، سرویس در چند ثانیه پسوال را بای‌پاس کرده تا اینترنت مستقیم خانه و دسترسی به روتر قطع نشود.
- 🧠 **امتیازدهی آگاه از توان پردازنده:** محاسبه جریمه سخت‌افزاری برای پروتکل‌های سنگین (مانند gRPC و QUIC) روی روترهای با پردازنده ضعیف (مانند ARMv7/Cortex-A7) و اولویت‌دهی به VLESS-Reality و ChaCha20.
- ⚡ **بنچمارک ۵۰ دی‌ان‌اس منتخب:** بررسی سرورهای بین‌المللی، امنیتی، حریم خصوصی و تحریم‌شکن‌های داخلی روی پورت‌های UDP 53 ،TCP 53 و DoH 443 همراه با شناسایی آلودگی و جعل دی‌ان‌اس (DNS Poisoning).
- ⚙️ **حالت دستی یا خودکار:** امکان تایید دستی پیشنهادات توسط کاربر یا سپردن صفر تا صد اعمال بهترین نود به دیمن خودکار.
- 📦 **سازگاری جهانی بدون نیاز به کامپایل:** پشتیبانی کامل و نیتیو از نسخه‌های مدرن اوپن‌دبلیو‌آرتی ۲۵ (`apk`) و نسخه‌های قدیمی‌تر (`opkg`).

## 🚀 نصب سریع با یک دستور (Single-Command Install)

از طریق SSH به روتر خود متصل شده و دستور زیر را اجرا کنید:

```sh
curl -sSL https://raw.githubusercontent.com/mortezabahmani/passwall-sentinel/main/install.sh | sh
```

*(در صورتی که مخزن خصوصی باشد، می‌توانید با کلون گیت مخزن را دریافت کرده و `sh install.sh` را اجرا کنید).*

```sh
git clone git@github.com:mortezabahmani/passwall-sentinel.git
cd passwall-sentinel
sh install.sh
```

## 💻 دستورات خط فرمان (CLI)

| دستور | توضیحات |
| :--- | :--- |
| `pwsentinel check` | اجرای بنچمارک کامل (نودها + ۵۰ دی‌ان‌اس) و ذخیره نتایج |
| `pwsentinel status` | مشاهده وضعیت فعلی نود فعال و پیشنهادات برتر |
| `pwsentinel apply` | اعمال نود و دی‌ان‌اس برتر با رول‌بک مسلح ۶۰ ثانیه‌ای |
| `pwsentinel rollback` | بازگشت فوری به آخرین اسنپ‌شات سالم قبلی |
| `pwsentinel test-nodes` | بنچمارک اختصاصی نودهای پسوال ۲ |
| `pwsentinel test-dns` | بنچمارک اختصاصی ۵۰ سرور دی‌ان‌اس |
| `pwsentinel failsafe` | اجرای دستی چست سلامت و فعال‌سازی اضطراری در صورت قطعی |

## 🖥️ محیط گرافیکی تحت وب (LuCI)

پس از نصب، در محیط وب روتر به مسیر زیر بروید:
* **خدمات (Services) ➔ PassWall Sentinel**
* آدرس مستقیم: `http://192.168.1.1/cgi-bin/luci/admin/services/pwsentinel`

در این صفحه می‌توانید:
1. وضعیت نود فعال و پیشنهادات برتر را در قالب کارت‌های داشبورد مشاهده کنید.
2. با کلیک روی **⚡ Run Benchmark Now** تست زنده بگیرید و جدول کامل نتایج را ببینید.
3. با کلیک روی **✅ Apply Recommendation** بهترین تنظیمات را اعمال کنید.
4. با کلیک روی **⏪ Rollback Snapshot** در صورت لزوم به وضعیت قبل بازگردید.
5. بازه زمانی تست‌های خودکار (هر چند ساعت یا روز) را تعیین کنید.

## ⚙️ تنظیمات (`/etc/config/pwsentinel`)

```uci
config settings 'main'
    option enabled '1'                     # فعال بودن سرویس پس‌زمینه
    option auto_apply '0'                  # 0: نیاز به تایید من | 1: اعمال تمام‌خودکار
    option check_interval '6h'             # بازه تست: 1h, 2h, 6h, 12h, 1d, 1w
    option max_nodes_to_test '5'           # تعداد نودهای برتر برای تست عمیق
    option failsafe_enabled '1'            # نگهبان نجات اضطراری
    option failsafe_loss_threshold '3'     # حد آستانه خطا پیش از بای‌پاس
    option bypass_mark '255'               # مارک سوکت برای خروج مستقیم از اینترنت خام
```
